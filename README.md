# Print Queue Consolidator

- `python/consolidator.py` – linked-list queues + heap-based k-way merge (the real algorithm).
- `python/test_consolidator.py` – unit tests: `cd python && python3 -m unittest -v`
- `web/` – React + Tailwind + GSAP visualiser. Python runs in-browser via Pyodide.

Run: `cd web && npm install && npm run dev`
